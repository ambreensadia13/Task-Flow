
# TaskFlow – Task Management System

TaskFlow is a responsive React-based task management and productivity dashboard.

## Features

- Dashboard with productivity statistics
- Create, read, update and delete tasks
- Task descriptions and due dates
- Categories, tags and priority levels
- Search, filter and sorting
- Bulk task deletion
- Drag-and-drop Kanban board
- Monthly calendar
- Productivity analytics
- Dark mode
- JSON backup export and import
- Browser LocalStorage persistence
- Responsive design

## Technology Stack

- React.js
- JavaScript
- CSS3
- Vite
- Lucide React
- Browser LocalStorage

## Installation

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

## Production Build

```bash
npm run build
```

## Data Storage

Tasks are saved in browser LocalStorage. Data belongs to the browser and device used to create it.

Export a JSON backup before clearing browser data or changing devices.

## Purpose

This project demonstrates React development, component-based UI, CRUD operations, state management, browser storage, and responsive interface design.
